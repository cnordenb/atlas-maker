name: limits
description: >
  Make sure the codebase remains digestible using simple limits.
---

## 1. LOC

No line of code may exceed 120 characters.

## 2. Functions

No function may exceed 60 lines of code.

## 3. Files

No file may exceed 400 lines of code.

## 4. Directories

No directory may exceed 7 files, except for directories of assets and data.
